# TruckDeck-Lite
This would be my first version (V0.1) of the TruckDeck Lite. It is a realistic panel build for truck simulators with a realistic layout full of useful buttons in all kinds of forms (switches, rotary encoders, momentary switches, ...). This way, simmers can have an affordable piece of sim gear that makes the simulator more immersive.

### AI Disclosure:
For now, I only used AI for finding (cheap) components that are nececary for my build. And a bit for making my idea into a concept (removing things that were not realistic).
